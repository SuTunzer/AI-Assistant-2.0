How the estimate works

Speech uses 25 audio tokens per second and approximately 200 script text tokens per minute, with speech text input priced at US$0.50 per million. Choosing another speech model may also change its text input rate; this comparison leaves that small input rate unchanged. Each briefing includes the selected context and output overhead. Chat estimates include the selected context and all billable output. Retry reserve is applied to the AI/news subtotal, then infrastructure is added. Currency conversion and the extra buffer apply to the total.

Sonnet: US$2 input / US$10 output per million tokens. Opus: US$5 / US$25. Context caching discounts and promotional credits are excluded. Capture, news and infrastructure are explicit allowances; their own workloads are not automatically inferred from episode count.

This is an engineering budget estimate. It excludes development labour, a paid domain, subscription upgrades and any news licence surcharge. One user, usage-based hosting and modest stored data are assumed. A ten-minute daily habit is close to the target; a six-minute mix leaves more room for chat.
